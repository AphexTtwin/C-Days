# C++ Exercises

A curated collection of C++ practice modules and exercises, organized by topic and difficulty.

## Overview

This repository contains C++ coursework-style exercises grouped into module folders (`C00` to `C09`). It is intended as a clean public record of C++ learning, problem-solving, and implementation practice.

## Contents / What’s inside

- Module directories: `C00` to `C09`
- Exercise subfolders (for example `ex00`, `ex01`, `ex02`)
- C++ source files (`.cpp`) and headers (`.hpp`)
- Makefile-based builds in multiple exercise folders (notably in later modules)

## Technologies

- C++
- GNU Make
- Standard C++ compiler toolchain (`c++`/`g++`/`clang++`)

## Build instructions

Build commands may vary by exercise folder. If a `Makefile` is present:

```bash
make
```

For a direct compiler build (when needed):

```bash
c++ -Wall -Wextra -Werror -std=c++98 *.cpp -o program
```

Then run:

```bash
./program
```
